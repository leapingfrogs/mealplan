# Cooklang canonical tests

`canonical.yaml` is Cooklang's official parser test suite (spec version 8),
copied unchanged from
[cooklang/spec](https://github.com/cooklang/spec/blob/0510646ca2196dd0b69e7ea2ae3f3de29f7b686e/tests/canonical.yaml)
at commit `0510646ca2196dd0b69e7ea2ae3f3de29f7b686e`. It is MIT licensed; see `LICENSE`.

`Mealplan.Cooklang` must pass every case (ADR 13). To update, copy the file
from a newer commit, update the commit above, and fix or explain any new
failures.
